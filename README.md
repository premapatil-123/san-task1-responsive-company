# SanTech - Responsive Company Website

## Internship Task

SAN Web Technology Full-Stack Development Internship

### Level 1 - Task 1: Responsive Company Web Pages

## Project Description

SanTech is a responsive company website created as part of Level 1 Task 1 of the SAN Web Technology Full-Stack Development Internship.

The project demonstrates a browser-side foundation using HTML, CSS, and JavaScript.

## Pages

### 1. Home
Introduces SanTech and highlights its modern, responsive and user-friendly approach.

### 2. About
Provides information about the company's mission, work and approach.

### 3. Contact
Provides contact information and an accessible contact form with JavaScript validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features

- Semantic HTML structure
- Responsive design
- Shared visual design across all pages
- Navigation between Home, About and Contact pages
- Accessible contact form
- JavaScript form validation
- Mobile-friendly layout
- Git version control
- GitHub repository
